# MINISHELL

## As beautiful as a shell 💻 !!!

# Description

**Minishell is a simplified implementation of a shell based on Bash. The main goal of this project is to deeply understand how a terminal works internally, dealing with process lifecycle, memory management, file descriptor handling, and communication between programs using pipes.**

**The project challenges you to create a program capable of reading commands, interpreting them, handling variable expansions, and executing them in a robust way, while properly managing system signals and syntax errors.**

# Instructions

## Compilation

- **The project uses a Makefile to automate the compilation process. To compile the program use:**

```
    >$ make
```

Use `make re` to recompile the entire project

`make clean` will delete all object files generated by the compilation

`make fclean` command will clean up the object files and the final `minishell` program

- **This will generate the executable file ``minishell`` in the root if the repository.**

## Execution

- **To start the shell, run:**
```
    >$ ./minishell
```
## Usage

- **Once inside Minishell, you can execute commands just like in Bash:**

1. Simple commands: ``ls -la``, ``pwd``, ``echo hello``

2. Pipelines: ``cat file.txt | grep "42" | wc -l``

3. Redirections: ``ls > output.txt``, ``grep "pattern" < input.txt >> log.txt``
